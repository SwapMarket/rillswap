# Security policy

RillSwap is pre-release and has not been audited. Do not use it with funds.

Report suspected vulnerabilities privately through the hosting platform's
private vulnerability reporting feature. If that feature is unavailable,
contact the maintainers through the private security address in the signed
release metadata. Do not include secrets, private keys, or mainnet funds in a
report.

A stable public security contact and disclosure key are release gates.
